# ✅ CORREÇÃO PARA PORTUGUÊS DE PORTUGAL

**Padrão**: PT-PT (não PT-BR)

---

## 📋 **CORREÇÕES COMUNS**

### **1. Vocativos (Tu/Você)**
| ❌ Incorreto (BR) | ✅ Correto (PT) |
|------------------|----------------|
| Você | Tu |
| Seu/Sua | Teu/Tua |
| Conosco | Connosco |

### **2. Conjugações Verbais**
| ❌ Incorreto (BR) | ✅ Correto (PT) |
|------------------|----------------|
| Aceite (imperativo) | Aceita |
| Registe | Regista |
| Actualize | Atualiza |
| Viste | Viste (mantém, mas "vieste" é o imperfeito) |

### **3. Terminologia Específica**
| ❌ Incorreto (BR) | ✅ Correto (PT) |
|------------------|----------------|
| Usuário | Utilizador |
| Senha | Palavra-passe |
| Aplicativo | Aplicação |
| Login | Início de sessão |
| Logout | Fim de sessão |
| Criar conta | Criar conta / Registo |
| Fazer login | Iniciar sessão |
| Fazer logout | Terminar sessão |

### **4. Exemplos de Frases**
| ❌ Incorreto (BR) | ✅ Correto (PT) |
|------------------|----------------|
| "Você quer fazer login?" | "Queres iniciar sessão?" |
| "Registe-se aqui" | "Regista-te aqui" |
| "Usuário criado" | "Utilizador criado" |
| "Senha inválida" | "Palavra-passe inválida" |
