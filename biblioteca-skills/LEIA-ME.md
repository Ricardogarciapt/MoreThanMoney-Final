# Biblioteca de skills

Skills em português (kursku/skills, 06/10/2026) que **não** estão em uso diário. Ficam aqui, fora de
`.claude/skills/`, para que as descrições não entrem no contexto de cada sessão do Claude Code (poupança
de tokens, 17/11/2026, padrão `agent-sort` do ECC: DAILY vs LIBRARY).

Para usar uma: `cp -r biblioteca-skills/<nome> .claude/skills/` (ou `git mv` se passar a ser diária).
