PRE-STREAM CHECKLIST
═══════════════════════════════════════════════════════════════════════════════

Before your first stream, verify:

EQUIPMENT:
  □ Microphone is connected and working
  □ Camera is positioned at eye level
  □ Good lighting (avoid backlighting)
  □ Internet connection is stable (5+ Mbps upload recommended)
  □ No background noise/clutter

OBS STUDIO:
  □ All scenes are visible and properly named
  □ Stream key is correctly configured
  □ Camera source is active
  □ Microphone input shows audio levels
  □ Overlay PNG is rendering correctly
  □ Chat browser source is loading

TEST STREAM:
  □ Start a test stream (without announcing it)
  □ Let it run for 2-3 minutes
  □ Check video/audio quality in the dashboard
  □ Verify chat is functional
  □ Review the test recording
  □ Make any adjustments needed
