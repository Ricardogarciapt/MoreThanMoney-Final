# 🔭 Scanner Suite Installation Guide

## Overview
This module provides the GoldKiller and MTM Scanner functionality.

## Setup
1. Copy `web/` to your Next.js `app/` directory.
2. Copy `api/` to your Next.js `app/api/` directory.
3. Ensure the `core-engine/lib/` is available for TradingView and Signal logic.
4. Set environment variables for TradingView API if applicable.
