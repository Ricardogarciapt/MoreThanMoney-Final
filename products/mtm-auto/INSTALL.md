# ⚡ MTM Auto Installation Guide

## Overview
Automated copying and performance tracking system.

## Setup
1. Copy `app/` to your Next.js `app/` directory.
2. Copy `api/` to your Next.js `app/api/` directory.
3. Install the `engine/` logic into your VPS/Server for the Copy-Engine to run.
4. Configure `MTM_AUTO_PROV_KEY` in your .env.
