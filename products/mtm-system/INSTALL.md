# 📱 MTM System Installation Guide

## Overview
Mobile-first experience including alerts, terminal, and app shells.

## Setup
1. Copy `web/` to your Next.js `app/` directory.
2. Use `shells/` to configure Capacitor for iOS and Android.
3. Ensure Firebase Cloud Messaging (FCM) is configured for `alertas-mtm`.
4. Run `npx cap sync` to deploy to native devices.
